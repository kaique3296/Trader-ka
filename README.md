# Robô BTC/BRL — nuvem Android / apenas simulação

[**Instruções detalhadas para executar pelo Android**](README_ANDROID.md)

Projeto experimental, para operar somente com dinheiro virtual. Não solicita chaves de corretora, não contém endpoints de ordens, e nunca pode comprar ou vender criptoativos reais. `python -m unittest discover -s tests -v` verifica componentes locais; o acesso online a preços da Binance só pode ser validado durante uma execução real do workflow no GitHub.
